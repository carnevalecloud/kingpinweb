## Engine build
`engine/scripts/build.sh` exports the pinned commits to `engine/.build`, builds GL4ES then the engine, and writes
`public/engine/upstream/` with `build-info.json` (hashes). The first build downloads the SDL2 port.

Findings:
- A single parallel `make` fails: the client link needs the side modules without depending on them. Build
  `ref_soft ref_gl1 ref_gles3 game` first, then `client`.
- Upstream documents editing GL4ES's CMakeLists to add `-fPIC`; `-DCMAKE_C_FLAGS=-fPIC` does the same.
- `SOURCE_DATE_EPOCH` is set from the Qwasm2 commit. `--verify-reproducible` compares two clean builds.

## Tests
| Suite | Covers |
| --- | --- |
| `tests/unit` | Parsers, malformed and truncated input, VFS, file planning, CLI, asset guard |
| `tests/e2e/engine` | Startup, rendering, gravity, collision, diagnostics on synthetic data |
| `tests/e2e/play`, `site` | File selection, persistence, inspector page |
| `tests/e2e/kingpin` | Original maps. **Skipped** unless `gamedata/main` holds `Pak0.pak` and `textures/` |

Fixtures are generated by `tests/fixtures/builders.ts`, including a BSP room. Software WebGL makes the engine
tests slow (a few minutes in total).

To enable the original-map tests, copy `main/Pak0.pak` and `main/textures` from your installation into
`gamedata/main/`. Their screenshots and logs go to `gamedata/reports/`; never commit them.

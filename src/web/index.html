KINGPIN//WEB

An in-progress browser compatibility engine for Kingpin: Life of Crime (1999). It needs your own copy of the game and ships none of its files. The game is not playable yet.

  • Map walkthrough (experimental): walk your maps. No characters or gameplay yet.
  • Model browser: inspect and preview original MDX and MD2 models.
  • Asset inspector: examine your game files. Everything stays in this browser.
  • Upstream engine: the unmodified Qwasm2 (Quake II) build. Without Quake II-compatible data it stops during startup. Checking engine build…

The engine is GPL software. Source revisions and these licences are published with it: engine, GL4ES, SDL, Emscripten, musl. Project source code (GPL-2.0-or-later).
